## Tech Lead qarorlari
- **Bir xil origin:** Next.js `rewrites` orqali `/api/v1/:path*` → `API_INTERNAL_URL` (server env, default `http://localhost:3001`). Brauzer faqat web origin'ga murojaat qiladi — cookie'lar (`rt`, `ps`, `parent_tokens`) `SameSite=Strict` va `Path` bilan muammosiz ishlaydi, CORS kerak emas. `API_INTERNAL_URL` ni `.env.example` ga qo'sh.
- **Access token faqat xotirada** (Zustand `stores/auth.store.ts` — faqat client holati: `accessToken`, `user`/`role`, `status`). localStorage/sessionStorage'ga token YOZILMAYDI. Sahifa yangilanganda sessiya `POST /auth/refresh` (cookie + `X-Requested-With`) bilan tiklanadi.
- **API client** (`src/lib/api/`): bitta `fetch` o'rami — base `/api/v1`, `Authorization: Bearer`, `credentials: 'include'`, JSON, xatolarni `ApiErrorBody` ga parse qilib tiplangan `ApiError` (code, status, details) tashlaydi. 401 bo'lsa bir marta refresh → so'rovni qayta yuborish. **Refresh "single-flight":** bir vaqtda kelgan barcha 401'lar BITTA refresh so'rovini kutadi (parallel refresh backend'da reuse detection'ni ishga tushirib sessiyani o'ldiradi — 1.5 hisobotidagi ogohlantirish). Refresh muvaffaqiyatsiz → store tozalanadi → login sahifasiga.
- **Server ma'lumotlari faqat TanStack Query** (`QueryClientProvider` bitta provider faylda). `me` va boshqalar store'ga nusxalanmaydi (store'da faqat token va minimal identifikatsiya — asosla).
- **Formalar:** `react-hook-form` + `@hookform/resolvers/zod` + `@lms/shared` sxemalari (yoki asoslangan muqobil). Server xatolari (`VALIDATION_ERROR` details, 401 umumiy xabar, 429) formada ko'rsatiladi.
- **Route'lar** (docs/03):
  - Public (`AuthLayout`): `/login` (student: ID + parol), `/login/staff` (telefon + parol), `/change-password` (majburiy), `/parent` (ota-ona kirishi va farzandlar).
  - Rol bosh sahifalari (hozircha bo'sh, `EmptyState` bilan): student → `/path`; mentor → `/mentor`; admin va super admin → `/admin`; ota-ona → `/parent`.
  - Layout'lar: `StudentLayout`, `MentorLayout`, `AdminLayout` (super admin uchun qo'shimcha menyu bandlari), `ParentLayout` — `AppShell` + `TopBar` + `Sidebar`/`NavItem`. Menyu bandlari docs/03 §0 jadvalidan (hali yo'q sahifalar — havola bor, lekin bosilganda oddiy "Tez orada" `EmptyState` sahifasi yoki `disabled` NavItem — asosla, 404 bo'lmasin). StudentLayout yuqori panelidagi streak/XP/coin/bildirishnoma — 5-bosqichda; hozir TopBar'da faqat ism va "Chiqish".
  - Student menyusidagi "Mentor" bandi: docs/03 da student `/mentor` sahifasi mentor paneli `/mentor` bilan to'qnashadi — **egasidan so'ralmoqda (S-69)**. Hozir student menyusida "Mentor" bandini `disabled` qilib qo'y, route yaratma.
- **Route guard'lar** (rol bo'yicha): client tarafda — sessiya tiklanguncha `Spinner`; tiklanmasa tegishli login sahifasiga (student zonasi → `/login`, staff zonalari → `/login/staff`); noto'g'ri rol → o'z bosh sahifasiga; `mustChangePassword=true` → har qanday himoyalangan sahifadan `/change-password` ga. Login'dan keyin rolga mos bosh sahifaga. Kerak bo'lsa Next `middleware` faqat oddiy cookie mavjudligi bo'yicha yo'naltirish uchun (token tekshiruvi backend'da) — asosla.
- **Ota-ona oqimi** (docs/02 §5.1, docs/10):
  - `/parent?t=<token>`: sahifa ochilishi bilan tokenni URL'dan DARHOL olib tashla (`router.replace('/parent')`), `POST /auth/parent/exchange {tokens:[t], merge:true}`.
  - `/parent` cookie bilan: avval body'siz exchange (sessiyani yangilash) → muvaffaqiyatli bo'lsa farzandlar kartochkalari (`GET /auth/me` → `children`), aks holda token kiritish formasi.
  - "Farzand qo'shish": token kiritish → `merge:true`. "Chiqish" → `POST /auth/logout`.
  - Farzand kartochkasi bosilganda `/parent/:studentId` — hozir `EmptyState` (14-bosqich).
  - Ota-ona sahifalari faqat o'qiydi, hech qanday mutatsiya tugmasi yo'q (exchange va logout bundan mustasno).
  - `Referrer-Policy: no-referrer` ni `/parent` uchun Next `headers()` orqali ham qo'y.
- **Change password:** `mustChangePassword` bo'lsa majburiy (boshqa joyga o'tib bo'lmaydi, faqat "Chiqish"), muvaffaqiyatda yangi access token store'ga, rolga mos bosh sahifaga.
- **Feature tuzilmasi:** `src/features/auth/{components,hooks,api,types,index.ts}`, `src/features/parent-access/...`, layout'lar `src/features/shell/...` yoki `src/app` route group'lari (`(auth)`, `(student)`, `(mentor)`, `(admin)`, `(parent)`) — docs/13 §3 ga mos tanla. Features bir-birining ichki fayllarini import qilmaydi (faqat `index.ts`) — depcruise tekshiradi.
