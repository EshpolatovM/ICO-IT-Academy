## Aniq vazifa
1. **Parent token CRUD** (`/students/:id/parent-tokens[/:tokenId]`, `.../regenerate`): docs/02 §5 va §7. Token `crypto.randomBytes(32)` → base64url (43 belgi), bazada `HMAC-SHA256(PARENT_TOKEN_PEPPER, token)`, `token_prefix` (8). Xom token faqat yaratish/regenerate javobida bir marta qaytadi (havola formati docs'ga qarab: `/parent?t=...` — frontend bazaviy URL config'dan). Faol tokenlar limiti (S-17: 3) va boshqa raqamlar — config'da nomlangan qiymat (SettingsService 5-bosqichda; izoh qoldir). Regenerate = revoke + create bitta tranzaksiyada. Revoke'da Redis `parent_token:{id}:valid` keshi o'chiriladi. Ruxsat: SA, A; mentor — `ScopeGuard` (hozir yopiq).
2. **`POST /auth/parent/exchange`** (`@Public`): docs/12 §1 formatida — `{ tokens: string[], merge: boolean }` yoki body'siz (cookie'dagi tokenlar bilan yangilash). Har bir token HMAC bo'yicha topiladi, revoked/expired/INACTIVE student rad etiladi. Natija:
   - `ps` cookie: parent session JWT (`sub=parentTokenId` yoki docs'dagi tuzilma, `role=PARENT`, `studentIds`), 12 soat sliding (config), `HttpOnly; SameSite=Strict; Secure=COOKIE_SECURE`.
   - `parent_tokens` cookie: xom tokenlar server kaliti bilan **shifrlangan** (AES-256-GCM, kalit `PARENT_COOKIE_KEY` env'dan), `Path=/api/v1/auth/parent`, `Max-Age` 180 kun (S-16, config). `merge=true` mavjudlarga qo'shadi; bekor qilingan tokenlar cookie'dan olib tashlanadi.
   - Javob: `{ children: [{ studentId, firstName, lastName, groupName }] }` — `groupName` hozircha `null` (guruhlar 2-bosqichda; tipda nullable, izoh bilan).
   - `last_used_at`, `use_count` yangilanadi, `parent_access_logs` ga `EXCHANGE` yoziladi.
   - Rate limit (docs/02 §5): IP bo'yicha 10 urinish / 15 daqiqa, 20 muvaffaqiyatsiz → IP 1 soatga blok. Mavjud `LoginRateLimiter` ni umumlashtirib qayta ishlat (DRY), raqamlar config'da.
   - Token logga yozilmaydi (faqat prefix). Javobga `Referrer-Policy: no-referrer`.
3. **Parent autentifikatsiyasi:** `JwtAuthGuard` (yoki alohida strategiya) `ps` cookie'ni tanib `RequestUser{role:PARENT, studentIds}` beradi; har so'rovda tokenlar hali amalda ekani Redis keshi orqali tekshiriladi (revoke → keyingi so'rov 401). `GET /auth/me` parent uchun ham ishlaydi (docs/12: "ANY + P"; javob shakli parent uchun — bolalar ro'yxati, asosla). Parent "chiqish": ikkala cookie ham o'chiriladi (`POST /auth/logout` parent uchun ham, yoki docs'ga qarab).
4. **`ParentReadOnlyGuard`** (global, Roles'dan keyin): PARENT faqat `GET` va `/auth/parent/*`, `/auth/me`, `/auth/logout` ga; qolgan har qanday metod → 403. Parent faqat `studentIds` ichidagi bolaga kira oladi — buni tekshiradigan umumiy mexanizm (decorator/helper) tayyorlab qo'y (`/parent/children/:id/*` endpointlari 14-bosqichda).
5. **`ScopeGuard` karkasi:** interfeys (`StudentScopeResolver` kabi) — SA/A: hamma; MENTOR: faqat o'z guruhlaridagi studentlar (guruhlar yo'q → hozir har doim rad, 2-bosqichda haqiqiy implementatsiya bilan almashtiriladi; izoh); STUDENT: faqat o'zi. `@StudentScope('id')` kabi dekorator bilan ishlatiladi. Unit test bilan.
6. **Parol tiklash:** `POST /students/:id/reset-password` (SA, A; M — ScopeGuard), `POST /staff/:id/reset-password` (A → faqat MENTOR; SA → ADMIN va MENTOR; o'zini tiklash mumkin emas). docs/02 §4.3: vaqtinchalik parol (10 belgi, kriptografik tasodifiy, `passwordSchema` ga mos), `must_change_password=true`, `token_version++` (Redis kesh yangilanadi), refresh tokenlar bekor, javob `{ temporaryPassword }` faqat bir marta.
7. **Audit servisi:** `AuditService` + `AuditLogsRepository` (`audit_logs`), `actor`, `actorRole`, `action`, `entityType`, `entityId`, `before/after` (parol/hash/token HECH QACHON yozilmaydi), `ip`. Action kodlari `@lms/shared` da (`PASSWORD_RESET`, `PARENT_TOKEN_CREATED`, `PARENT_TOKEN_REVOKED`, `PARENT_TOKEN_REGENERATED` ...). Shu vazifadagi barcha mutatsiyalar audit qilinadi. `GET /super/audit-logs` hozir QILINMAYDI.
8. **Env:** `PARENT_TOKEN_PEPPER`, `PARENT_COOKIE_KEY`, `PARENT_SESSION_TTL_SECONDS`, `PARENT_TOKENS_COOKIE_MAX_AGE_SECONDS`, `PARENT_MAX_ACTIVE_TOKENS`, exchange rate limit qiymatlari, `WEB_BASE_URL` (havola uchun) — zod sxemada (sirlar uzunligi tekshiriladi), `.env.example` da joy to'ldiruvchilar, lokal `.env` ga tasodifiy qiymatlar.
9. Sxemalar va javob tiplari `@lms/shared` da (front ham ishlatadi).
