## Aniq vazifa
1. **Tailwind CSS v4** ni `apps/web` ga o'rnat (Next 15 bilan rasmiy usul: `@tailwindcss/postcss`), aniq pin, kamida 2 hafta oldin chiqqan stable. Global CSS: `src/styles/globals.css` → `@import "tailwindcss"` + `tokens.css`.
2. **`src/styles/tokens.css`** — yagona manba: CSS o'zgaruvchilari (yuqoridagi semantik nomlar + tipografiya, bo'shliq, radius, soya). Tailwind v4 `@theme` faqat shu o'zgaruvchilarga murojaat qiladi (masalan `--color-primary: var(--lms-color-primary)` yoki to'g'ridan-to'g'ri `@theme` ichida — v4 uchun eng toza usulni tanla va asosla). Maqsad: Tailwind klasslari faqat semantik nomlar bilan (`bg-primary`, `text-muted`, `border-border` ...). Tailwind standart rang klasslarini (`bg-blue-600`, `text-gray-900` ...) ishlatishni texnik jihatdan bloklash yoki lint bilan taqiqlash yo'lini taklif qil/qo'lla (masalan `@theme` da standart ranglarni `--color-*: initial` bilan o'chirish) — shunda sahifalarda token'siz rang yozib bo'lmaydi.
3. **`src/components/ui`** — har biri alohida faylda, `index.ts` orqali eksport, tiplar aniq, accessibility (label/aria, focus-visible ring, disabled), `forwardRef` (React 19 `ref` prop) kerak bo'lsa:
   - `Button` (variant: primary, secondary, ghost, danger; size: sm, md; `loading`, `disabled`, `fullWidth`; `asChild` kerak bo'lsa Radix `Slot`)
   - `Input` (text/password/tel; xato holati), `PasswordInput` (ko'rsatish/yashirish tugmasi bilan)
   - `Label`, `FormField` (label + input + yordam matni + xato matni, `id`/`aria-describedby` bog'langan)
   - `Card` (+ `CardHeader`, `CardTitle`, `CardContent`, `CardFooter`)
   - `Alert` (info, success, warning, danger)
   - `Spinner`
   - `Heading`/`Text` (tipografiya token'lari bilan; sahifalarda xom `<h1 className=...>` yozilmasligi uchun)
   - Layout karkas elementlari: `Container`, `Stack` (vertikal/gorizontal, gap token'lari bilan), `AppShell` (yuqori panel + yon panel slotlari + kontent — rol panellari uchun bo'sh karkas), `TopBar`, `Sidebar` + `NavItem` (aktiv holat)
