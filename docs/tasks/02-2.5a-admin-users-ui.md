## Vazifa
Sahifalar (hozirgi `(admin)/admin/[...section]` stub o'rniga haqiqiy route'lar):

1. **Studentlar** — `/admin/students` (SA, A)
   - Jadval: ID (`ST-…`), ism-familiya, status (Badge), yaratilgan sana; saralash (`-createdAt` standart, `createdAt`, `lastName`, `-lastName`), qidiruv `q` (debounce), filtr `status`, pagination (`page`, `pageSize` ≤ 100). Holat URL query'da saqlanadi.
   - Guruh filtri (`groupId`) va guruh ustuni uchun **joy qoldiriladi** (2.3 tayyor emas) — disabled Select yoki "Tez orada", kod tuzilmasi keyin ulashga tayyor bo'lsin.
   - Yaratish (Dialog yoki alohida sahifa): `createStudentSchema` (`@lms/shared`), javobdagi `temporaryPassword` → `SecretReveal`, **react-query keshiga yozilmaydi**.
   - Tafsilot/tahrirlash `/admin/students/[id]`: `firstName`, `lastName`, `status` (`updateStudentSchema`); deaktivatsiya/aktivatsiya = `status` PATCH, `ConfirmDialog` bilan; parolni tiklash `POST /students/:id/reset-password` → yangi vaqtinchalik parol `SecretReveal` da.
   - CSV import: `FileInput`, maydon nomi `STUDENT_IMPORT_FILE_FIELD`, ≤ 1 MiB; muvaffaqiyatda yaratilganlar va parollar ro'yxati (bir marta, keshsiz); 400 `VALIDATION_ERROR` → `details: [{row, field, message}]` jadval; 413 `PAYLOAD_TOO_LARGE` xabari.
2. **Mentorlar** — `/admin/mentors` (SA, A): ro'yxat (qidiruv, status, saralash, pagination), yaratish (`createStaffSchema`, telefon + ism), tahrirlash (`updateStaffSchema`), deaktivatsiya, parol tiklash `POST /staff/:id/reset-password`. "Guruhlari" ustuni — 2.3 dan keyin, hozir joy qoldiriladi.
3. **Adminlar** — `/admin/admins` (faqat SA; admin uchun menyuda ko'rinmaydi va route 403/redirect): `/super/admins` bilan xuddi Mentorlar kabi.

Xatolar: 409 `CONFLICT` `details.field="phone"` → telefon maydoniga xato; o'z akkauntini PATCH → 403 xabari. Yuklanish, bo'sh holat, xato holatlari ko'rsatiladi.
