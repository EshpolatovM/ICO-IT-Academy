## Aniq vazifa
1. **ESLint qat'iy qoidalar** (`@lms/config` bazasida, hamma paketga tarqaladi):
   - `typescript-eslint` type-aware (`recommendedTypeChecked` yoki `strictTypeChecked` — tanlovni asosla), `@typescript-eslint/no-explicit-any: error`.
   - `max-lines: 300` (skipBlankLines, skipComments), `max-lines-per-function: 50`, `complexity` (limit nomlangan, masalan 10), `max-depth`, `max-params`.
   - Import tartibi (`eslint-plugin-import-x` yoki `eslint-plugin-import`, ESLint 9 flat bilan mos), `no-unused-vars`/`unused-imports` — error.
   - `no-magic-numbers` (yoki `@typescript-eslint/no-magic-numbers`) — mantiqiy istisnolar bilan (0, 1, -1, test fayllari, enum/const e'lonlari).
   - `linterOptions: { reportUnusedDisableDirectives: 'error', noInlineConfig: true }` — `eslint-disable` taqiqi avtomatik.
   - Frontend (`apps/web`) uchun: uzun nisbiy importlarni taqiqlash (`no-restricted-imports` bilan `../../*` pattern), alias'lar majburiy.
   - Test fayllari (`*.spec.ts`, `*.e2e-spec.ts`) uchun `max-lines-per-function` yumshatilishi mumkin — sababini yoz.
2. **jscpd:** ildizda `.jscpd.json`, `apps` va `packages` bo'yicha, `threshold` (masalan 3%), dist/.next/node_modules ignore. Ildiz skript `pnpm dup`.
3. **dependency-cruiser:** ildizda `.dependency-cruiser.cjs`. Qoidalar:
   - `*.controller.ts` → faqat service/dto/guard/decorator; `*.repository.ts` ni import qilmaydi.
   - controller va service `@prisma/client` yoki prisma servisini to'g'ridan-to'g'ri import qilmaydi (faqat `*.repository.ts` va `src/infra/prisma/**` mumkin).
   - `apps/web/src/features/X/**` boshqa `features/Y` ning ichki fayllarini import qilmaydi (faqat `features/Y/index.ts` orqali).
   - `apps/web` va `apps/api` bir-birini import qilmaydi; umumiy narsa faqat `@lms/shared`.
   - Sikl (circular) taqiqi, orphan ogohlantirish.
   Ildiz skript `pnpm depcheck` (yoki `pnpm arch`). Qoidalar hozirgi bo'sh skeletda o'tishi va ataylab buzilgan namunada (vaqtinchalik faylda, keyin o'chir) xato berishi kerak.
