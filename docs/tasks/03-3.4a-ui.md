## Vazifa (har biri alohida faylda, `index.ts` orqali eksport, a11y, testlar, design-preview'da)
1. **`ProgressBar`**: `value` (0–1), `label`, foiz matni; `role="progressbar"`, `aria-valuenow`/`min`/`max`.
2. **`StatusIcon` / `NodeStatusBadge`**: LOCKED / AVAILABLE / IN_PROGRESS / COMPLETED (va sandiq uchun LOCKED / READY / OPENED). Rang emas, matn va oddiy belgi bilan (wireframe), faqat mavjud semantik token'lar.
3. **`PathNode`**: xarita tuguni. `kind: 'TOPIC' | 'CHEST'`, `title`, `status`, `lessons`/`lessonsCompleted` (mavzu uchun), `href?` (LOCKED bo'lsa havola emas, `aria-disabled`), `current?` (joriy pozitsiya belgisi). Sandiq tuguni `disabled` tugma, tooltip/tavsif "keyinroq" (ochish 5-modulda).
4. **`PathSection`**: bo'lim sarlavhasi + progress + tugunlar ro'yxati (vertikal zanjir, `ol`/`li`).
5. **`TreeList`**: admin daraxti uchun ichma-ich ro'yxat. Har bir qatorda: sarlavha, status Badge, amallar slot'i, **"Yuqoriga" / "Pastga"** tugmalari (`onMoveUp`/`onMoveDown`, birinchi/oxirgida disabled), yig'ish/yoyish. Drag-and-drop YO'Q. `role="tree"`/`treeitem` yoki oddiy `ul` + `aria-expanded`: soddasini tanla va asosla.
