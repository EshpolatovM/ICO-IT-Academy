## Aniq vazifa
1. **Yo'llar (faqat o'qish):** `GET /admin/paths` (SA, A (GET: M ham)) — guruh formasi uchun `id`, `title`, `slug`, `status` ro'yxati (to'liq kontent CRUD 3-bosqichda).
2. **Guruhlar:** `GET/POST /admin/groups`, `GET/PATCH /admin/groups/:id` (SA, A): yaratish (`name`, `pathId`, ixtiyoriy `mentorId`, `startsAt`), ro'yxat (qidiruv, filtr `status`/`mentorId`/`pathId`, pagination, a'zolar soni, mentor ismi), tafsilot (faol a'zolar ro'yxati bilan), PATCH (`name`, `status` ACTIVE/ARCHIVED, `startsAt`). Arxivlangan guruhga a'zo qo'shib bo'lmaydi.
3. **Mentor biriktirish:** `PUT /admin/groups/:id/mentor` `{ mentorId | null }` — faqat ACTIVE MENTOR roli.
4. **A'zolar:** `POST /admin/groups/:id/members` `{ studentIds: uuid[] }` (bir nechta), `DELETE /admin/groups/:id/members/:studentId` (`left_at = now()`). Student boshqa faol guruhda bo'lsa → 409 (domen xato kodi `@lms/shared` da, `details` da qaysi studentlar). Ixtiyoriy "ko'chirish" kerak emas (avval chiqarish, keyin qo'shish).
5. **Haqiqiy `StudentScopeResolver`:** MENTOR → student uning ACTIVE (va o'chirilmagan) guruhlaridan birining FAOL a'zosi bo'lsa ruxsat; aks holda `false` → 404 (docs/01 §3). Kesh: Redis set `mentor:{id}:students` (TTL 60 s, kalit/TTL konstanta yoki config) — a'zolik qo'shilganda/chiqarilganda, mentor almashtirilganda, guruh arxivlanganda/o'chirilganda tegishli mentor(lar) keshi invalidatsiya. S-10 A: guruhdan chiqqan studentni eski mentor ko'rmaydi. Shu bilan mentor uchun `/students/:id/reset-password` va `/students/:id/parent-tokens*` endpointlari avtomatik ochiladi (1.6 dagi "hali yoqilmagan" 403 olib tashlanadi; testlar yangilanadi).
6. **Mentor endpointlari** (docs/12 §12): `GET /mentor/groups` (o'z guruhlari: nom, yo'l, studentlar soni — progress hozircha yo'q), `GET /mentor/groups/:id` (o'ziniki bo'lmasa 404), `GET /mentor/groups/:id/students` (ism, ID, status, oxirgi kirish — progress/XP/streak keyingi bosqichlarda; javob tipida ular uchun joy qoldirma, faqat mavjud maydonlar), `GET /mentor/students/:id` (scope orqali; profil: ism, kod, guruh, status, oxirgi kirish, ota-ona tokenlari soni).
7. **Ota-ona:** `children[].groupName` ni to'ldirish (parent exchange va `/auth/me` javoblarida).
8. **Deaktivatsiya bilan bog'liqlik:** 2.2 dagi student deaktivatsiyasi — faol a'zolikka tegmaydi (asosla) yoki chiqaradi — docs'ga qarab hal qil; mentor deaktivatsiyasi — guruhlardan `mentor_id` ni olib tashlash shart emas, lekin scope keshini invalidatsiya qil.
9. **Audit:** `GROUP_CREATED`, `GROUP_UPDATED`, `GROUP_MENTOR_ASSIGNED`, `GROUP_MEMBERS_ADDED`, `GROUP_MEMBER_REMOVED` — `UnitOfWork` bilan.
10. Sxemalar/tiplar `@lms/shared` da (strict). Qatlamlar: `modules/groups` (controller'lar: admin groups, admin paths, mentor), servislar bitta mas'uliyatli, repository'lar `BaseRepository`/`SoftDeletableBaseRepository` dan. `docs/12-api.md` §2, §12 ga so'rov/javob namunalari.
